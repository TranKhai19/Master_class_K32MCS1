Sơ đồ Luồng Dữ liệu Đa tầng (Hybrid RDBMS + NoSQL + Hadoop)

Chu trình xử lý từ Edge Sensors $\rightarrow$ NoSQL Hot Tier $\rightarrow$ Hadoop Data Lake Cold Tier $\rightarrow$ Analytics

Đồ án CSDL Nâng Cao
TẦNG 1

IoT Edge Gateways

30 thiết bị gửi log viễn thám qua giao thức MQTT / HTTP REST với tần suất 15-30 phút/lần.

Payload: JSON Stream
TẦNG 2: HOT STORE

MongoDB NoSQL

Lưu trữ linh hoạt Collections: device_telemetry & command_logs. Đánh compound index tối ưu truy vấn thời gian thực.

Indexing: {dev_id, ts}
TẦNG 3: COLD STORE

Hadoop HDFS / Lake

Định kỳ nén sang định dạng cột Parquet (Snappy) phân vùng year/month/day phục vụ lưu trữ dung lượng lớn dài hạn.

Format: Parquet / ORC
TẦNG 4: BATCH ANALYTICS

PySpark / MapReduce

Đối soát dữ liệu RDBMS MySQL với log HDFS: tính toán kWh, dò tìm quá nhiệt, quá tải và kiểm tra chính sách retention.

Engine: Spark Batch
TẦNG 5: VISUALIZATION

Command Center

Cung cấp báo cáo trực quan tức thời cho người dùng quản lý nhà thông minh và đối soát doanh thu quản trị viên.

UI: Flask & Chart.js
